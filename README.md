# 曜麟·天衡

一款基于抽选机制的奖励/惩罚轮盘工具，适用于课堂互动、活动抽奖、游戏环节等场景。  
内含 **普通模式** 和 **完全模式** 两种抽选流程，并支持自定义奖池与概率。

## 主要功能

- 🎲 **双模式抽选**  
  - **普通模式**：滚动动画，可随时停止，最终随机抽取结果。  
  - **完全模式**：后台静默抽选，播放对应星级全屏视频 + 手写签名板，仪式感满满。

- 🎬 **视频与 BGM 支持**  
  - 完全模式下根据抽中星级自动播放 `simple` 或 `special` 视频。  
  - 支持全局背景音乐循环播放（可选）。

- ✍️ **透明签名板**  
  - 视频结束后可在屏幕上自由涂鸦，模拟真实抽奖体验。  
  - 点击空白处可跳过签名，自动进入结果展示。

- 🌓 **自适应主题**  
  - 自动跟随系统亮色/暗色模式切换界面配色。  
  - 按钮圆角设计，美观大方。

- ⚙️ **灵活配置**  
  - 所有奖池、星级、概率均通过 `obj.json` 文件控制。  
  - 内置默认配置，可直接使用，也可按需修改。

- 📦 **4K 高分屏完美支持**  
  - 应用程序已启用 PerMonitorV2 DPI 感知，在高分辨率显示器上依然清晰。

## 如何使用

1. **启动程序**  
   双击 `bal.exe`（或安装后的快捷方式），即可打开主窗口。

2. **选择模式**  
   - 点击 **设置** 按钮，勾选“完全模式”启用高级抽选，取消则进入普通模式。  
   - 设置界面中可编辑项目配置文件 `obj.json`。

3. **开始抽选**  
   - 主窗口点击 **开始抽选**，程序将根据你设定的概率随机抽取奖项或惩罚。  
   - **普通模式**：奖项名称快速滚动，按 **停止抽选** 定格结果。  
   - **完全模式**：静默抽选后打开全屏视频窗口，完成签名后展示最终结果。

4. **查看结果**  
   主窗口中央显示当前抽选结果，星级以 ⭐ 符号呈现。

## 配置文件说明（`obj.json`）

配置文件位于程序目录下的 `resources/obj.json`，格式如下：

```json
{
  "levels": [
    {
      "star": 1,
      "probability": 78.5,
      "items": ["获得100金币", "获得经验值+50", "跳过一次作业"]
    },
    {
      "star": 2,
      "probability": 18.5,
      "items": ["打扫教室卫生", "写额外数学作业"]
    },
    {
      "star": 3,
      "probability": 3.0,
      "items": ["操场跑圈5圈", "背完整本语文课本重点"]
    }
  ]
}
```

- `star`：星级（影响完全模式播放的视频文件夹：`simple` 或 `special`）。  
- `probability`：该星级出现的概率（百分比），所有星级概率之和**建议为 100%**。  
- `items`：该星级下的具体奖项或惩罚列表。

修改后保存，程序会实时生效（下次抽选使用新数据）。

## 资源文件说明

程序依赖以下资源，默认已包含在安装包中：

- `resources/obj.json`：奖励配置。  
- `resources/img/title.png`：标题图片。  
- `resources/music/bgm.m4s`（或 `.mp3`）：完全模式背景音乐（可选）。  
- `resources/simple/`：星级 1-2 的视频文件（Start.mp4、Skip.mp4、Open.mp4）。  
- `resources/special/`：星级 3 的视频文件（Start.mp4、Skip.mp4、Open.mp4）。  

如需自定义视频，替换对应文件夹下的文件即可。
