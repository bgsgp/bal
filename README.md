## 🎯 项目简介

曜麟·天衡是一款趣味性抽选工具，支持 **普通模式**（滚动抽选）和 **完全模式**（视频动画 + BGM）。可自定义奖项、概率、星级，适用于课堂奖励、团队活动、个人决策等场景。

---

## ✨ 核心功能

- **双模式**：普通模式快速抽选，完全模式沉浸体验
- **星级系统**：1-3星，可配置不同概率和奖项，完全模式下播放对应视频
- **完全自定义**：通过 JSON 配置文件自由调整
- **主题自适应**：亮色/暗色模式自动切换

---

## 📥 下载安装

请从下方的 Releases 列表中选择最新正式版（v1.1），下载 `BlueArchiveLottery Installer.exe` 并运行。

**系统要求**：Windows 10 / 11 (64位)

---

## 📚 快速开始

1. 安装后首次运行，会自动生成默认 `obj.json`
2. 编辑 `obj.json` 自定义奖项和概率（可用记事本打开）
3. （可选）准备完全模式所需的视频和音乐资源（详见 README）
4. 点击“开始抽选”即可
